# Game media sources

Screenshots and original game descriptions come from the owner's itch.io pages. KonTEXTo's current GameInfo copy follows the owner-confirmed [Figma reference](https://www.figma.com/design/M6YiE4DPEACvwrWhLzm0LN/BSOD_Portfolio?node-id=2032-128), including Lead Unity Developer/Technical Artist roles and Task & Dialogue Manager / Text Editor System ownership. Screenshot order matches those galleries; trailer IDs come from their embedded videos. Local screenshots are WebP copies resized to 1600 px wide (quality 85); trailer posters are local WebP copies of YouTube's supplied posters. No remote image requests are needed at runtime. Update `src/data/games.ts` when replacing media or copy; no runtime scraping is used. Copy remains text, with paired `**...**` markers for emphasized phrases rendered as semantic `<strong>` elements. GameInfo renders Role, Contribution, Description / Game Info, and Game Features as always-visible chevron lists under thin paper bars. Extra engine/language/team/duration/classification/status fields remain stored but hidden, as requested. KonTEXTo uses the reference's plain body copy; existing emphasis markers remain supported for Anii. Centered trailers use native YouTube embeds with autoplay disabled; local posters are retained for neighboring visual copies.
