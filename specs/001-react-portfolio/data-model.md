# Data Model: Portfolio

## Project

A readonly TypeScript record defined in `src/types/project.ts`:

| Field | Type | Invariant |
| --- | --- | --- |
| `id` | `string` | Stable, nonempty, unique within collection |
| `title` | `string` | Readable title, e.g. `practice_axe.fbx`; do not include decorative brackets in its accessible name |
| `titleImageSrc` | `string` | Bundled outlined title artwork, visually matching this title |
| `imageSrc` | `string` | Bundled artwork URL |
| `imageAlt` | `string` | Descriptive alternative, not a filename-only label |
| `description` | `string` | Reference description; remains native readable text |

`src/data/projects.ts` exports a readonly array with the one supplied project. Validate authored data at review/type-check boundaries; no runtime schema library, fetch layer, or invented additional records.

## Carousel state

- Input: static readonly `projects` for this component instance.
- State: `activeIndex`, initially `0`.
- Derived: selected project and `canNavigate = projects.length > 1`.
- With zero projects: no selected card; previous/next disabled; never perform modulo zero.
- With one project: index `0`; both controls disabled.
- With `n > 1`: next becomes `(index + 1) % n`; previous becomes `(index - 1 + n) % n`. Use functional state updates.
- Title, title artwork, image, alternative, and description always derive from the same selected record. No independently stored copies of those fields.
- This page does not edit or reload collections. Replacement collections in a development harness remount the component; live collection mutation is not a requested API.

## Heading content

H1/H2 accept an `id`, a readable `label`, and an `artworkSrc`; H2 also accepts `description`. They own their design-specific layout and have no carousel/page state. Label content is native heading text; decorative artwork has empty alternative text.

## Background lifecycle

No new application data model. The existing renderer owns all transient animation/pointer state. React owns only setup and disposer invocation. Mount, cleanup, and remount leave exactly one active canvas while mounted and none after cleanup.

## Persistence

None. Reload starts the carousel at the first supplied project. Asset URLs are generated by Vite imports, not remote Figma URLs.
